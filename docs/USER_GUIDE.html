PDF 是这个工具的核心。所有 PDF 操作都基于纯 Python 库 pypdf + PyMuPDF， 不依赖 Adobe、不依赖浏览器内核。

PDF 合并 pdf_merge
把多份 PDF 按用户指定的顺序合并成一份。可以插入空白页、删除特定页。
输入
多份 PDF（≥ 2）
输出
单份 PDF
关键参数
文件顺序、插入空白页位置
适用场景
合并多章节报告、合订扫描件
PDF 拆分 pdf_split
两种模式：按页数均匀拆（每 N 页一个文件）和按页码范围拆（如 1-5,8,11-13 一份）。 拆出来的每个文件自动加上序号后缀。
输入
单份 PDF
输出
多份 PDF
关键参数
每段页数 / 页码范围列表 / 起始编号
适用场景
长文档分发给不同部门、按章节归档
提取指定页 pdf_extract
从一份 PDF 中按页码列表抽出部分页，合成一份新 PDF。
关键参数
页码列表（如 1,3,5-8）
适用场景
从报告抽出某一章、从合同抽出附件页
删除指定页 pdf_delete_pages
与"提取"相反 —— 按页码列表从原文件中删除。
适用场景
删除封面/空白页、移除机密页
PDF 旋转 pdf_rotate
把每页旋转 90°/180°/270°，常用于纠正扫描方向错误的文档。

在指定位置（左下/右下/居中等）加上页码，可设置字体大小和起始编号。

3Excel 处理（2 项）

基于 openpyxl，真实保留公式（不是把公式转成计算结果）， 同时保留字体、填充、边框、对齐、数字格式、列宽、行高、合并单元格、冻结窗格。

Excel 拆分 excel_split
按行拆分（每 N 行一个新文件）或按工作表拆分（每个 Sheet 一个文件）。 默认开启完整格式保留：单元格逐个 copy，连带公式字符串、样式、列宽行高、合并、冻结窗格。
输入
单份 xlsx
输出
多份 xlsx
关键参数
拆分方式（按行/按表）、每段行数、是否保留格式（默认是）
适用场景
把一年 12 个月报表拆成 12 份、把多 sheet 报告拆给不同人

Excel 合并 excel_merge
多份 xlsx 合并成一份。可以选择"新表"（每份作为一个 sheet）或"追加"（数据追加到同一表）。 自动处理表头去重。
关键参数
合并模式、是否去表头、输出 sheet 名规则
适用场景
合并各分公司月度数据、汇总各门店销售表
发票整理成表格 invoice_summary
把一批发票 PDF 解析成 Excel，首张 「按日期」表把同一天的花费合并成一行 （交通 / 餐饮 / 住宿 分列，附当日合计），可直接照着填报销单；另附发票明细、项目汇总、待确认。 出行票自动提取出发地→到达地（铁路票取出发站/到达站/车次，网约车票取出行栏），住宿票取酒店名称（销售方）， 餐饮票取餐厅名称；一张票多段行程合并为一行，按发票号码自动去重并校验金额自洽。 项目归属按文件夹结构判定：一个项目一个文件夹，项目名取第 1 层子目录名，无需给发票命名； 散在根目录的票进「待归属」。只支持有文本层的电子发票 PDF，扫描件不做 OCR，会明确列入「待确认」。 全程只读，不修改发票文件。
按日期表怎么看
一行 = 某项目的某一天：日期 / 星期 / 费用类别 / 费用明细 四列，金额按 交通·餐饮·住宿 分列，末列「当日合计」。表尾按类别小计、给总计。
两类票不按天算
① 住宿票票面只有开票日期、没有入住日期 → 记在开票日并在备注注明， 请你按实际入住日调整；② 一张票含多天行程（网约车月结）→ 单独成段、金额按整票计， 不摊到某一天，避免那天的行虚高。
关键参数
项目名（可选，留空自动按文件夹）、项目层级、去重、金额校验、每项目独立工作表
适用场景
报销汇总：把各项目的差旅发票一键整理成台账

虚拟打印设备过滤

下拉框只显示真实物理 / 网络打印机，以下"不会出纸"的设备一律隐藏， 避免误选后弹一堆"另存为"对话框、或静默多出一堆 PDF 文件：

  • Microsoft Print to PDF、Microsoft XPS Document Writer
  • 导出为WPS PDF、发送到WPS高级打印
  • OneNote、OneNote (Desktop)、Fax
  • 以及名字里带 PDF/XPS/虚拟打印机 等特征词的其它设备

一台真实打印机都没有时会怎样？（v1.0.3 起）打印功能仍然显示， 但标题会变成「PDF 批量打印（未检测到可出纸的打印机）」，打印机下拉框只剩占位项； 此时点「开始执行」会被拦下，并提示你连接打印机或改用「PDF 导出 PDF」。 这样功能入口永远找得到，不会再"莫名其妙消失"。

打印安全设计（v1.0.2 起）

打印是物理世界里收不回来的动作 —— 纸出了机器就回不去。所以本工具对 "出纸"这件事设了三道闸，任何一道没过都不会打印：
  1. 必须由人在界面上确认：点「开始执行」后，确认框会点名打印机、 文件数、合计份次、预计张数，点"是"才会真的提交作业。 测试脚本 / 批处理 / 定时任务等无人值守路径拿不到这个授权，会被直接拒绝。
  2. 「仅演练不打印」勾选框：勾上后一个作业都不提交，只把每份文件按当前 配置渲染成 xxx_预览.pdf 放到输出目录。建议第一次用、或换了纸张 配置时先演练一遍，确认版式没问题再取消勾选真打。
  3. 环境变量熔断：设置 ODA_NO_PRINT=1 后，该进程内所有真实 打印都会被拒绝（给自动化和排障用）。

纸张 / 方向 / 份数怎么生效

份数：按"每份文件提交 N 次作业、作业内份数固定 1"实现， 任意账户都生效，不需要管理员权限，也不会出现"驱动份数 × 作业份数" 叠乘打出一堆纸的情况。
纸张 / 方向 / 双面 / 颜色：通过本次作业专用的 DEVMODE 下发， 每份文件互不影响，不需要管理员权限，而且不会修改你的系统打印机默认设置。
极少数驱动可能不接受外部 DEVMODE，此时会退回打印机默认纸张，执行日志里 会写明原因（不会静默改掉你的设置）。

提示：如果你的打印机默认纸张不对（例如被 1.0.1 及更早版本改成了 A3 横向）， 可运行 python tools/fix_printer_defaults.py --restore "<打印机名>" 还原为 A4 纵向。

工作流程

  1. 选打印机（下拉框只显示真实物理打印机）
  2. 导入 PDF 文件（支持拖拽）
  3. 在表格表头设默认配置（纸张/方向/份数/双面/颜色）
  4. 需要特殊配置的行 → 双击单元格改值，或多选后点"套用默认到选中行"
  5. （建议）先勾选「仅演练不打印」跑一遍，打开输出目录核对预览 PDF 版式
  6. 确认无误 → 取消勾选 → 点"开始执行" → 在确认框里核对打印机/份数 → 点"是"
  7. 进度条显示进度，随时可点"取消"中断（已提交的任务会留在 Windows 队列，可手动清理）

11常见问题

Q1. Excel 拆分后公式变成数字了？

A：本工具默认开启"保留格式"，公式字符串（=SUM(A1:A10)）会被原样复制到新表， 打开新表时 Excel 会重新计算。如果你看到的是数字，那是因为勾选了"只保留值"——保持默认即可。

Q2. 批量打印时打印机列表是空的 / 打印功能"不见了"？

A：本工具会隐藏 Microsoft Print to PDF、导出为WPS PDF、 Microsoft XPS Document Writer 等虚拟打印设备，只显示真实物理打印机。 如果你的电脑没有装任何实体打印机（只靠 Windows 自带的虚拟设备），会出现两种情况： v1.0.2 及更早版本打印功能会整个从侧栏消失，且无任何提示； v1.0.3 起功能始终显示，标题会标注「未检测到可出纸的打印机」， 执行时也会解释原因。无论哪个版本，此时想生成指定纸张的 PDF 文件， 都请用 PDF 导出 PDF；想打纸质文件请先连接/安装实体打印机。

Q3. 会不会出现"我没操作，打印机自己开始打印"？

A：不会。v1.0.2 起真实打印必须由人在界面上点「开始执行」并在确认框里点"是"， 确认框会明确列出打印机名、文件数、合计份次与预计张数；测试、脚本、定时任务等 无人值守路径拿不到这个授权，会被直接拒绝（抛 PrintNotAuthorized）。 想彻底关掉出纸，还可以勾「仅演练不打印」或设置环境变量 ODA_NO_PRINT=1。

Q4. 打印纸张设置没生效？

A：v1.0.2 起纸张/方向/双面/颜色通过本次作业专用的 DEVMODE 下发， 不需要管理员权限、也不会改你的系统打印机默认设置。 如果日志里出现"本次按打印机默认纸张/方向提交"，说明该驱动不接受外部 DEVMODE （极少数驱动如此），此时内容仍按你选的纸张尺寸渲染，由驱动缩放适配； 要真正切换纸盒，请在 Windows「打印首选项」里给该打印机设置好纸张。

Q5. 打印机的默认纸张被改乱了怎么恢复？

A：1.0.1 及更早版本会持久改掉打印机默认设置（这是已修复的缺陷）。 先运行 python tools/fix_printer_defaults.py 看现状，再执行 python tools/fix_printer_defaults.py --restore "<打印机名>" 还原为 A4 纵向 / 1 份 / 彩色 / 单面。也可以直接在 Windows「打印首选项」里手动改回去。

Q6. 能处理加密的 PDF 吗？

A：加密 PDF 需要先在 PDF 解密 里输入密码解开，再做其他操作。如果 PDF 没设打开密码但设了修改密码， 大部分功能不受影响。

Q6. 一次能处理多少个文件？

A：技术无上限，但实际体验：

  • PDF 拆分/合并：500 份以内流畅
  • Office 转 PDF：受 Office 启动开销限制，100 份左右建议分批
  • 批量打印：≤ 200 份推荐，超过请关注打印机队列
  • 批量重命名：5000 份以内流畅

Q7. 跨平台能用吗？

A：核心功能（PDF / Excel / 转换 / 批量）跨平台。打印仅 Windows。Office 转 PDF 在 macOS 上需要 LibreOffice（命令行），Windows 上用本机 Office。
